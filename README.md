# sanctumboard.com

The public shopfront for **SanctumBoard — governance, with proof**.

Static HTML + CSS (no build step). Deploys anywhere that serves files:
- **Vercel**: import this repo, framework "Other", no build command, output directory `.` — then add the domains `sanctumboard.com` and `www.sanctumboard.com`.
- Docker/nginx (legacy): `docker compose up`.

Related properties:
- Live product: https://demo.sanctumboard.com
- AI governance assessment: https://assess.sanctumboard.com
- Documentation: https://docs.sanctumboard.com

The commercial arm is kept separate from the community: nothing on this site
links to or mentions the community property.
